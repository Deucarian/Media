# Changelog

## 0.1.0

- Added typed media sources and loader strategies.
- Added cancellation/version-aware media load coordination.
- Added explicit disposable resource leases.
- Added playback session contracts and immutable snapshots.
- Added Unity audio loading and video playback adapters.
- Added the narrow pooled `UnityAudioOneShotOutput` used by semantic audio clients, with safe clip/volume/pitch validation and explicit stop-all support.
